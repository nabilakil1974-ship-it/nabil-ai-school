Powers

A shorter way to write repeated multiplication of the same number.

THE IDEA
2 × 2 × 2 × 2 = 24 = 16

The base is 2. The exponent is 4: it tells us how many times the base is used as a factor.

EXAMPLE A
32 = 3 × 3 = 9
EXAMPLE B
53 = 5 × 5 × 5 = 125
EXAMPLE C
102 = 100
EXAMPLE D
71 = 7
IMPORTANT RULES

For any non-zero number a:

a1 = a    ·    a0 = 1

A power with exponent zero equals 1, provided the base is not zero.

Think like a mathematician: in 43, how many factors of 4 do you multiply? Read the exponent, then expand the power.

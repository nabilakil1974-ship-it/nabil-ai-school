## LL-24 — Construction tools on EVERY construction step
Any step that constructs (segment of given length, angle of given measure, arc of given radius) must show the ruler, protractor or compass on screen while it draws, then remove the tool. Use the generic `construct` draw function (ops: ruler, protractor, arc, mark, line, perp) rather than a static figure. Reference implementation currently lives in the published lesson `app/static/NABIL_G07_EN004_method14_v4.html`; it still has to be ported into `golden_v6_engine.js`. Not yet applied to construction scenes with unspecified data (23–25) or on book images (58).

## LL-25 — Student-facing pages carry no internal text
No QA, source-page, guide, Golden/V6, teacher-note or developer wording in anything the student sees (DOM text, SVG text, captions). Audit all scenes in every language before publishing (visible-text scan).

## LL-26 — Three languages: Arabic / English / French
Every step has `en` and `fr` (twins of `text`), draw steps `speech_en` and `speech_fr`, scenes `title_fr`. Three always-visible language buttons (عربي / English / Français), the chosen one highlighted (not a single cycling button — user feedback). French speech normaliser reads ≅ "est isométrique à", ↔ "correspond à", angle hat as "angle X". Greeting and closing message exist in all three. Still to port into the factory engine and the solver prompt.

## LL-27 — Factory now produces all of this itself (ported 2026-10-21)
Engine `golden_v6_engine.js`: `construct` draw (ruler/protractor/compass ops), 3 language buttons (`setLang`, `step.ar/en/fr`, `speech_*`, `title_*`), French speech normaliser, spoken greeting before the lesson. Solver: `app/services/exercise_solver.py` asks for `construct` per construction step and validates it (`_clean_construct`); `golden_v6_solver.js` turns it into a draw step. Gate: `factory/student_clean_gate.py` is enforced inside `render_golden_v6_board` (raises `STUDENT_TEXT_DIRTY`). Guard: `scripts/test_factory_requirements.py`. UNVERIFIED: no live provider run (no keys/egress); only synthetic scenes were rendered.

## LL-28 — Teacher plan follows the language chosen on the board
The plan (تحضير) opens in the language of the active button (ar/en/fr) and re-renders when the button changes while it is open. Idea titles, steps and formulas come from the step twins (`PLAN.tw`, built in `lesson_plan.py` from `title_*`/`ar`/`en`/`fr`), not from machine translation. CRDP structure is still UNVERIFIED against an official template.
